# Basdat_project

Berikut merupakan hasil dari tugas basis data yaitu membuat website database menggunakan PHP, SQL, dan Xampp.
Website yang kami buat adalah website peminjaman ruangan di Kampus, yang dimana user bisa pesan dan mengisi semacam form ruangan yang yang akan dibookingnya.
Lalu setelah terkirim, dari admin bisa memantau dan melihat keseluruhan data yang diisi oleh users. Selanjutnya, ruangan yang telah di pesan maka akan otomatis di booked dan tidak akan diambil users lain, karena sistemnya tergantung siapa yang lebih cepat mengisi.
